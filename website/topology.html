Network boundaries

OPNsense separates the home network from three purpose-built VLANs and controls permitted access between them.

The HP Z2 runs Proxmox and hosts OPNsense, web01, hch01, and dns01. All access to the lab VLANs passes through the OPNsense VM. The diagram omits addresses, VPN configuration, management endpoints, and camera connection details.

System roles / 02

How the lab fits together

HP Z2 / Proxmox

The physical host runs Proxmox and provides the virtualisation and VLAN-aware networking layer for OPNsense and the service VMs.

OPNsense

The firewall VM provides VLAN gateways, DHCP, inter-VLAN policy, and termination for trusted remote VPN access.

Admin workstation

The main administration point uses SSH and web interfaces to manage permitted infrastructure and services.

Internal DNS

dns01 in VLAN 30 resolves internal service names. DNS requests from other VLANs pass through OPNsense.
