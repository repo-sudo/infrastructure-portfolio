Concepts in practice

Virtual resources

Proxmox runs on the Z2 and allocates virtual CPUs, memory, and disk to each guest. A virtual CPU shares time on the host processor; it is not a dedicated physical core.

Bridge + address

The VM's VirtIO adapter connects through vmbr0 to the local network. The bridge carries the traffic; DHCP assigns the VM an IP address so other devices can reach it.

ISO + virtual disk

The Debian ISO on local boots the installer. After installation, Debian and the website live on the VM's virtual disk, independent of the installer ISO.
