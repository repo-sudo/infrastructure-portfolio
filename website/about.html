Purpose / 04

About this lab

I am building this lab to turn infrastructure theory into something I can operate, break, recover, and explain.

It started with one Proxmox host and a web server. It now includes segmented VLANs, an OPNsense firewall/router, internal DNS, backup testing, monitoring, and a deployment workflow.

Host
HP Z2 running Proxmox VE.
Network edge
OPNsense VM providing routing, DHCP, firewall rules, and VLAN gateways.
Core services
Portfolio website, Home Control Hub, internal DNS, and Uptime Kuma monitoring.
Current focus
Recovery testing, network segmentation, monitoring, and deployment automation.
