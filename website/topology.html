System roles / 02

How the lab fits together

HP Z2 / Proxmox

The physical host runs Proxmox and provides virtual VLAN connectivity for OPNsense and the service VMs. VM traffic, including traffic routed between VLANs by OPNsense, can remain inside the Z2.

OPNsense

The firewall VM provides VLAN gateways, DHCP, inter-VLAN policy, and termination for trusted remote VPN access.

Admin workstation

The main administration point uses SSH and web interfaces to manage permitted infrastructure and services.

Infrastructure services

dns01 resolves internal service names, while mon01 monitors core services, gateways, DNS, and internet reachability from VLAN 30.
