Concepts in practice

Virtual resources

Proxmox runs on the Z2 and allocates virtual CPUs, memory, storage, and network adapters to each guest while keeping services separated.

Segmentation

VLAN 10 separates the web server from the home LAN, while VLAN 20 now hosts the Home Control Hub. OPNsense rules decide which systems can cross between segments.

Recovery habits

Firewall configuration backups, static addressing, documented rules, and repeatable deployment steps make the lab easier to restore after changes.
