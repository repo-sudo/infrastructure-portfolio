System roles / 02

How the lab fits together

HP Z2 / Proxmox

The physical host runs Proxmox and provides virtual VLAN connectivity for OPNsense and the service VMs. VM traffic, including traffic routed between VLANs by OPNsense, can remain inside the Z2.

OPNsense

The firewall VM provides VLAN gateways, DHCP, inter-VLAN policy, and termination for trusted remote VPN access. A scoped destination NAT rule on its home-facing WAN address gives home devices access to Jellyfin.

Admin workstation

The main administration point uses SSH and web interfaces to manage permitted infrastructure and services.

Infrastructure services

dns01 resolves internal service names, while mon01 monitors core services, gateways, DNS, and internet reachability from VLAN 30. admin01 provides Ansible administration when powered on.

Media service

media01 runs Jellyfin through Docker Compose in VLAN 40. Debian and configuration use SSD storage; media uses a separate 400 GiB HDD virtual disk mounted read-only into Jellyfin. Phone access and TV casting are tested.

Home media access

Home clients use OPNsense’s home-network address on TCP 8096, forwarded to Jellyfin with scoped access. This local path does not require a Jellyfin internet port forward on the Virgin Hub. Media DNS naming, monitoring, and backups remain pending.
