Concepts in practice

What this lab is teaching

Virtual resources

Proxmox allocates virtual CPUs, memory, and disk to each guest. A vCPU shares time on the host processor; it is not a dedicated physical core.

Bridge + address

The VM's VirtIO adapter connects through vmbr0 to the local network. The bridge carries the traffic; DHCP assigns the VM an IP address.

ISO + virtual disk

The ISO boots the installer. After installation, the operating system and website live on the VM's virtual disk.
